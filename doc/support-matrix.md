Every supported case is compiled by xbintsc and run under Node; the
[conformance suite](../tests/conformance/conformance.test.ts) asserts byte-identical stdout. Every
unsupported case must fail with the listed diagnostic code. Because the suite
runs on every CI platform, this table cannot claim more than the compiler does.

## Supported cases (differential against Node)

| Case | Area | What it pins down |
| --- | --- | --- |
| `numeric-boundaries` | Values and operators | IEEE-754 special values, precision limits and safe-integer checks |
| `bigint` | Values and operators | BigInt literals keep full precision and describe themselves correctly |
| `coercion-and-equality` | Values and operators | `+`, relational and loose equality coerce like ECMAScript |
| `utf16-length-and-search` | Strings (UTF-16 semantics) | length/indexOf/code points follow UTF-16, not bytes |
| `array-pipeline` | Arrays | map/filter/reduce/at/spread and destructuring compose |
| `object-literal-and-spread` | Objects | computed keys, methods, `this` and object spread preserve shape |
| `classes-and-super` | Classes and inheritance | fields, constructors, statics, inheritance, super and instanceof |
| `closures-and-defaults` | Closures and functions | captured locals survive, defaults and rest parameters work |
| `try-catch-finally` | Exceptions | subclassed errors, catch binding and finally ordering |
| `await-ordering` | Async and promises | await suspends, queues a microtask and preserves interleaving with sync code |
| `json-round-trip` | JSON | stringify/parse round-trips nested values and key order |
| `map-and-set` | Map and Set | insertion order and identity-based deduplication |
| `regexp-match-replace` | Regular expressions | capture groups, test and global replacement on ASCII text |
| `typed-array-and-dataview` | Typed arrays and binary data | Uint8Array indexing, iteration and DataView byte access |
| `date-utc` | Date | UTC construction, ISO formatting and parsing agree |
| `generator-protocol` | Generators | yield, spread and manual next() drive the same generator |
| `esm-imports` | Modules | default, named and namespace imports across bundled modules |
| `optional-chain-and-template` | Optional chaining and templates | optional chaining, nullish fallback and template substitution |

## Unsupported cases (expected diagnostics)

| Case | Area | Diagnostic | Why |
| --- | --- | ---: | --- |
| `namespace-declaration` | Modules | TS4005 | `namespace` is parsed but not lowered |
| `new-target` | Closures and functions | TS4005 | `new.target` has no lowering |
| `angle-bracket-assertion` | Optional chaining and templates | TS2001 | `<T>value` assertions are rejected; use `as T` |
| `with-statement` | Optional chaining and templates | TS2001 | `with` is rejected by the parser |
